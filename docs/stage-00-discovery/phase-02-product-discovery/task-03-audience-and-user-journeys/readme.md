# Task 03 — Audience & User Journeys

## 1. Task ID & Title
`task-03-audience-and-user-journeys` — Audience Segmentation & User Journey Mapping

## 2. Objective
Model distinct user personas and map concrete, optimized interaction journeys for each audience segment across the dual-plane platform.

- Define personas: Recruiter, Engineering Leader, Commercial Client/Founder, Product Owner.
- Map step-by-step user journeys and conversion touchpoints.
- Define keyboard shortcuts and fast-track evaluation mechanisms.

## 4. Acceptance Criteria
- User journeys documented with entry points, actions, and success outcomes.
- Sub-60-second recruiter path verified.
