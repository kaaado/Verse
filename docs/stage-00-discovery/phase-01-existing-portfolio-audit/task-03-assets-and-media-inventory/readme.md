# Task 03 — Assets & Media Inventory

## 1. Task ID & Title
`task-03-assets-and-media-inventory` — Audit Static Media, Images, Videos & Icons

## 2. Objective
Catalog all images, SVG icons, animations, and static media files in the historical portfolio, evaluating which assets are suitable for reuse or optimization.

## 3. Scope
- Inspect `public/` and `src/assets/`.
- Inventory tech stack SVG icons.
- Audit heavy raster assets and Lottie JSON animations.
- Formulate asset reuse recommendations.

## 4. Acceptance Criteria
- All static assets inventoried.
- File sizes and formats cataloged.
- Asset reuse recommendations documented.
