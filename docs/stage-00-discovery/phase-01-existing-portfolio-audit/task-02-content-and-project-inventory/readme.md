# Task 02 — Content & Project Inventory

## 1. Task ID & Title
`task-02-content-and-project-inventory` — Catalog Projects, Experience & Content from Historical Systems

## 2. Objective
Catalog and reconcile all projects, client engagements, credentials, and professional content from the historical portfolio database and codebase.

## 3. Scope
- Reconcile Firestore database records with source code.
- Classify projects by strategic tier and domain.
- Inventory academic credentials and certifications.
- Record GitHub repositories, live URLs, and technology stacks.

## 4. Acceptance Criteria
- All 17 projects cataloged with verified attributes.
- Credentials inventoried.
- Classification into Tier 1 Flagship, Tier 2 Highlight, and Tier 3 Lab completed.
